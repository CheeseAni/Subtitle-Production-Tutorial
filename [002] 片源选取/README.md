## 概述

片源的选取是很重要的，不同源的画质可能大相径庭，选择最高画质的片源才是上上策。

不仅不同源之间画质有区别，可能帧数也有区别，这就会导致轴会有偏移，所以涉及 ASS 操作的组员之间用同一源才行。

如果是 BD，可能画面内容与 Web 有区别，存在画面的增减等情况，这就更麻烦了。

## 常见源

### TV

TV 源是各电视台广播的，因为广播标准古老，  
所以使用的编码标准落后、码率不高，且存在模拟信号干扰等问题，导致画质极差。

在有 Web 源的情况下，不会使用 TV 源。

*部分情况下会从 TV 源获取日文字幕*

#### 新旧时代日本 TV 大致区别

|        |       旧 TV       |    新 TV     |
| :----: | :---------------: | :----------: |
|  年代  |       2000        |     2010     |
|  编码  | 模拟信号 / MPEG-2 | MPEG-2 / AVC |
| 分辨率 |       480i        |    1080i     |

### Web

Web源是各流媒体网站上线的视频，平均画质就是B站动画的画质水平。

随着时代发展，流媒体逐渐取代传统媒体。

### DVD

DVD，即 Digital Video Disc，高密度数字视频光盘，  
一种古老的媒体存储介质，用来卖给观众。

存储密度低，且编码标准老，导致画质极差。

一般为 480i MPEG-2

### BD

BD，即 Blu-ray Disc，蓝光光盘，  
因存储密度远高于 DVD，且标准更先进，所以现在用 BD 存储动画并销售是市场主流。

可以把 BD 的作用理解为加密的U盘，售卖 BD 是动画制作方盈利的一种方式，  
由于是本地播放，码率自然远高于流媒体，因此这是消费级市场上画质最好的源（极个别 BD 比 Web 烂）。

## 画质对比

BD 未发售时(也就是动画连载阶段)，  
有 Web 源首选画质最高的平台的源，  
无 Web 源就只好退而求其次，选择画质一坨的 TV 源了。

使用 TV 源时，因为其本身画质极差，所以可以加上简单的预处理（滤镜），可以大幅度改善观感。  

一般情况下：  
BD > Web > 新 TV > DVD > 旧 TV

常见 Web 源画质：  
CR > NF > AMZN > Bili  
除了 CR 绝大多数情况下画质领先，其他流媒体站看情况选择

## 音质对比

BD 源有无损 2ch 音频，有的存在 6ch 的音频

Web 源大多都是 128kbps AAC，不过偶尔存在 E-AC-3 之类的更高的音质源

在挑选 Web 源时，优先考虑画质，音质好点差点基本听不出来  

一般情况下：  
BD (无损) > Web (128k AAC)

常见Web源音质：  
Bili (192k AAC) >= CR (128k AAC) ≈ Others  
AMZN ≈ NF (杜比) >= Bili (192k AAC) >= CR (128k AAC) ≈ Others
