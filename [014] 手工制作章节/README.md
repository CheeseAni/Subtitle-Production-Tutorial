## 前置知识

MKV 的章节存储的值是时间戳（ns），假设章节 a 的时间戳是 n，那么在跳转到章节 a 时，  
播放器可能跳转到离 n 最近的一帧，也可能跳转到 n 的向上取整的一帧（前提是播放器要关闭按关键帧跳转）。

时轴教程提到过 ASS 的时轴的区间性，所以 Aegisub 既能看到帧的时间戳，又能拿到两帧正中间的时间戳。

## 实操

### 编辑章节文件

在 MKVToolNix GUI 的 `章节编辑器` 中可以新建、载入、编辑、导出章节文件。

编辑章节前，先在设置里将章节编辑器的模板设为 `Chapter <NUM>`，语言标签 `en`。  
（因为中文系统语言会导致默认的模板是中文的模板）

在 Aegisub 中用滚动到章节要跳转的那帧，此时视频栏下方的帧时间就是当前帧 n 的时间戳，  
按 Ctrl+3，此时字幕的开始时间就是 n 与 n-1 正中间的时间戳，  
为了方便解释，假设这个正中间的时间戳叫做 n-0.5，此时需要计算出 n-0.25 的时间戳，  
目的是防止播放器取最近帧而不是向上取整，n-0.25 同时符合了这两个要求。

右键第一章，在该项后新建章节，  
将 n-0.25 输入到章节的开始时间。

需要注意：

1. 第一章的开始时间永远都是 0。

2. 不要设置章节的结束时间，结束时间对于播放器跳转是没有意义的。

3. 不要新建额外条目，播放器对多条目的兼容性很差，实际播放时也不会手动切换条目。

4. 可以给一个章节设置多个不同语言标签的名称，理论上播放器会根据用户的语言选择展示的名称。  
   要 en 名称放在第一个，因为播放器兼容性差，不兼容的播放器只会展示第一个名称。

5. 如果你需要的章节名称仅仅是序号，例如 `Chapter 1`，那么可以不设置名称，播放器会自己展示序号，支持多语言的播放器还会使用当前语言的序号。

### 封装章节

在混流器的输出页面中，章节栏中有输入章节文件的选项，输入刚才保存的章节文件。

不要乱设章节的字符集，刚才保存的是 UTF-8，不设字符集就默认是 UTF-8，所以不要动它。

输入章节文件后，即可混流。
